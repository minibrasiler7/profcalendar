🔲 Test de l'outil Grille

Testez le nouveau bouton grille dans le lecteur PDF

🔍 Instructions de test :

  1. Chargez un fichier PDF avec le bouton "Charger un PDF"
  2. Cherchez le bouton grille (🔲) dans la barre d'outils d'annotation
  3. Cliquez sur le bouton grille pour l'activer/désactiver
  4. La grille devrait apparaître/disparaître sur la page
  5. Chaque carré de la grille fait exactement 1cm × 1cm
  6. Testez le zoom : la grille garde ses proportions de 1cm
  7. Testez avec différentes pages si le PDF en a plusieurs
  8. Testez les deux modes (Enseignant et Étudiant)
